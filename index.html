Settings

Filters, theme, CSV export, and CSV import live here so the dashboard view stays clean.

CSV import matches rows by ticker and updates any columns you edited. Imported values are saved locally in your browser, not pushed to GitHub.

Using built-in static data. Importing a CSV updates this browser and saves the edited values on this device.

Ticker/exchange baseline was checked against Nasdaq Trader symbol directory files and exchange-code definitions. Nasdaq market codes used here: Q = Nasdaq Global Select Market, G = Nasdaq Global Market, S = Nasdaq Capital Market. Other-listed exchange codes used here: N = NYSE, P = NYSE Arca, Z = BATS/Cboe BZX.

Static data can be edited directly in the stocks array, or updated locally through CSV import in the Settings tab.
